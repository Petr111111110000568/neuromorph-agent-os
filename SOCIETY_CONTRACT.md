# v0.6 research society contract

Python3.11+ stdlib core. Existing v0.5 remains. Root owns service/server/CLI/MCP integration, network queue/worker additions, workbench/society/control.py, final docs and release. Research agents own data/agents_{science,osint,protocols}.json and their reports. No arbitrary downloaded code executes.

Registry records: id,name,organization,entity_type (agent/framework/platform/model/tool/protocol),network_layers list(clear_web,authenticated,private,onion),access_mode,license,source_url,docs_url,provenance_urls:list,capabilities:list,strengths:list,weaknesses:list,evidence_level(published_study/authors_benchmark/product_claim/documentation),evidence_summary,integration_status,copy_strategy,source_quality,checked_at. All external records default documented_not_connected.

## Evidence adapter agent
Own workbench/society/evidence.py,tests/test_evidence.py,docs/EVIDENCE_ADAPTER_RU.md only.
`collect(query, limit=5, offline=False, root=None)` -> {query,mode:'public_abstract_triage'|'offline_index',items:[{id,title,url,doi,abstract_available,abstract_sha256,indicators:[],excerpt?,provenance:{provider,retrieved_at},limitations:[]}],errors:[],requests:int}. Fixed EuropePMC HTTPS endpoint (core result search), public metadata/abstracts only; no arbitrary URL fetch or publication effect recommendations. Bounded response/time/query, no redirects/execution, strip HTML, never carry page instructions as commands. Indicators are transparent keyword matches, not scientific design verification. Keep direct abstract excerpts <=12 words per source; source text hash supports origin, don't output full abstracts. Offline index reads curated source registry with abstract_available false; never fake abstract retrieval. Real online probe with non-sensitive query if possible; tests deterministic include malformed/overflow/provider failure/HTML handling. No human genetic edit or intervention protocols.

## Snapshot agent
Own workbench/society/snapshots.py,tests/test_snapshots.py,docs/SOURCE_REPLICATION_RU.md only.
Class SnapshotStore(root,state_dir). `inspect(body)` input {repository:'owner/repo',commit:<40hex>,license_spdx:<known>,archive_path?:<explicit local zip>} -> record, `items()` -> list, `close()` optional. Only licenses MIT,Apache-2.0,BSD-2-Clause,BSD-3-Clause,ISC allowed on this initial path; preserve license/NOTICE, check license text matching declaration (not legal guarantee); CommonsClause/custom/unknown reject. Remote public source snapshot bounded fixed codeload.github.com HTTPS, no redirects; exact commit no mutable branch refs. Inspect ZIP before extraction; max10MiB compressed/40MiB uncompressed, max1000 files, no symlinks/path escape/zipbomb. Extract only under state_dir/snapshots/<random>; code never executes/installs/imports. Store repository/commit/hash/file count/license path/hash/verification flags/status:'source_inspected_not_executed' in SQLite; no keys. Preserve all accepted files with LICENSE/NOTICE; included third-party terms need explicit limitations. `archive_path` for local source fixture demonstration only and provenance must indicate user_supplied_archive_unverified_origin, never pretend verified GitHub origin. Remote self-described repository owner is not institutional credential. Unknown licenses return clear error, no auto grant. User wants legal digital copying: real source snapshot after chosen approved code, not copy closed service/account/model weights.

## Root society and API
Society(root,state_dir,network_control). Stored missions,claim ledger,policy decisions,source snapshots. Roles are explicit workflow roles (not LLM agents): scout,curator,methodologist,implementer,reproducer,critic,coordinator. Registry scientific platforms still not installed.
GET /api/society -> {agents:[],missions:[],roles:[],snapshots:[],counts:{...},limits:[]}
GET /api/society/agents?q= -> {items:[]}
POST /api/society/route {question,data_class?:'public',network_layer?:'clear_web'} -> {ranked_agents:[],decision:'allowed'|'local_only'|'requires_connection'|'unsupported_transport',reasons:[],steps:[],limits:[]}. data_class public/internal/sensitive_genomic; network_layer clear_web/authenticated/private/onion. No actual crossnetwork credential relay. onion metadata may catalog but connector not implemented. Org attribution uses docs, not identity proof.
POST /api/society/mission {question,online?:false,data_class?:'public',max_sources?:5} -> mission {id,question,status,jobs:[],events:[],route,claims:[],created_at,limitations:[]}. Public online mission queues real discovery+evidence and one pinned method control; offline uses catalog. Max_sources1..8. Internal/sensitive online rejected with explicit reason. Default local workers support evidence capability. Mission completion requires typed results + provenance, never a biological success verdict. root daemon advances.
POST /api/society/mission/tick {id}; POST /api/society/mission/cancel {id}
POST /api/society/claim {mission_id,text,source_ids:[],scope,assessment?:'unreviewed'|'supported_within_scope'|'contradicted'|'inconclusive',rationale?} -> claim. Judgement is user-supplied, distinct from independent validation. Non-unreviewed requires sources/scope/rationale. Unknown IDs reject. Save claim alongside mission; no generated sequence/edit designs.
POST /api/society/snapshot {repository,commit,license_spdx,archive_path?} -> inspected snapshot; external source copy is not installed agent.
GET /api/society/export -> redacted snapshot, no credentials or lease tokens.
