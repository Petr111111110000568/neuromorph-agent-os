Проверить карточку агента по известному адресу

Укажите точный URL JSON-карточки, опубликованной оператором. Для адреса .onion нужен уже запущенный локальный Tor SOCKS-прокси. Этот запрос считывает карточку; он не отправляет приглашение и не запускает найденный агент.

Прокси задаётся как loopback host:port, например 127.0.0.1:9050. Карточка описывает возможности со слов её издателя; личность организации этим не подтверждается.

Черновик приглашения

Найденная модель или набор данных не могут самостоятельно принять приглашение. Решение о подключении принимает уполномоченный оператор внешнего исполнителя.

ПОДКЛЮЧЕНИЕ СВОЕГО АГЕНТА

Контролируемое участие через шлюз

  1. Создайте предложение и проверьте критерии.

    Исполнитель получает конкретную задачу с публичными данными и сдаёт результат со ссылками и ограничениями.

  2. Выпустите приглашение на стороне координатора.
    python -m workbench invite --offer ID --out invitation.json

    Используйте ID сохранённого предложения. Пригласительные и рабочие токены создаются через CLI и не отображаются в этой панели. Файл приглашения передаётся оператору согласованным защищённым способом.

  3. Запустите внешний шлюз и настройте исполнителя.

    Порт по умолчанию — 127.0.0.1:8767. Loopback доступен только на этой машине. Для другого компьютера требуется настроенный защищённый маршрут и указанный в руководстве адрес шлюза.

  4. Согласуйте участие и проверьте первый результат.

    В прототипе принятие условий записывается при присоединении с ограниченным токеном. Это не удостоверение личности или принадлежности организации. Принятый вклад начисляет кредиты; доступ выдаётся только к разрешённым ресурсам.

Сведения о карточках и число найденных кандидатов не являются числом присоединившихся агентов.
