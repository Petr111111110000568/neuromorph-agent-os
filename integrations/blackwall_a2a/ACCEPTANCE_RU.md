# Акт приёмки Blackwall A2A HTTP+JSON subset 0.1

Дата: 2026-10-17. Среда испытания: изолированный контейнер Linux/Python 3.13, без доступа к openKylin, интернету, личным токенам и системным службам пользователя.

**Фактический результат:** 15/15 тестов `python -m unittest discover -s tests -v` успешно завершены; `python -m compileall` прошёл. Включены настоящие TCP-сокеты localhost с двумя независимыми HTTP-серверами и собственными SQLite; Qwen не вызывался.

## Проверено

- A2A HTTP+JSON AgentCard v1.0 / SendMessage / GetTask / ListTasks с реальными HTTP-запросами.
- Bearer-аутентификация, отказ 401 с чужим или отсутствующим токеном.
- Версионирование A2A 1.0, отказ старым версиям.
- Предметный allowlist `status`, `audit`, `cognition`, `plan X Y` на фиксированном адресе локального Blackwall v1.5.
- Отказ при произвольных URL, вводе shell, имитации подмены инструкции, посторонних полях, неправильном формате и слишком большом теле.
- Одна запись для повторного messageId; конфликт разных тел с одинаковым ID — отказ 409.
- SQLite: сохранение результата, повторное чтение после новой инстанциации, отказ от ложного SUCCESS после прерывания.
- Цепочка SHA-256: выявление локального изменения старой записи.
- Пагинация 3 задач по 2 и 1 с HMAC-защитой курсора от изменения.
- Два локальных сокета/два разных токена/две базы: отсутствие совместной очереди и взаимного доступа.
- Отказ при недоступном backend без утечки внутренних деталей.
- Клиентская проверка объявленного `supportedInterfaces` и readback результата.

## Не проверено

- Настоящая установка на openKylin 3.0, реальная авторизация v1.5 и ответы Qwen.
- Транспорт через два разных физических компьютера, TLS/mTLS, реальный A2A Python SDK или официальная conformance-suite.
- Потоковый A2A, многооборотные задачи, webhooks, внешние личности агентов, полнота версии 1.0.
- Реальная научная независимость двух моделей, работа роботов, VLA, взаимодействие с конкретным чатом ChatGPT.
- Полный `python -m unittest discover -s tests -v` для существующего neuromorph-agent-os: исходный checkout был недоступен контейнеру по сети. Тесты нового модуля выполнялись изолированно; полный репозиторий должен быть проверен в CI.

## Безопасность

Система исполняет ТОЛЬКО чтение фиксированных API-путей localhost, не использует входящий запрос как системную инструкцию. Порт привязан к loopback. Требуются отдельные токены для A2A и локального Blackwall. В архиве нет базы, состояния, учётных данных, весов моделей или логов пользователя. Внешнюю публикацию/автоматическое подключение к сети использовать нельзя без отдельной проверки TLS, контроля доступа и изоляции.
