# Локальный мост ассистентов 0.1

Разработано; установка и сквозной вызов через браузер должны проверяться отдельно. Мост не даёт API-доступа и не гарантирует авторизацию, получение ответа или поддержку текущего DOM всех платформ.

## Установка пользователем

1. В Edge откройте `edge://extensions/`, включите режим разработчика и выберите «Загрузить распакованное расширение». Укажите эту папку. Chrome использует `chrome://extensions/`.
2. Откройте панель расширения. Разрешайте сайты по отдельности; браузер покажет новые права. Для `yandex.ru` техническое разрешение охватывает домен, но код допускает только `/alice` и подпути.
3. Включите проверку разрешённых вкладок раз в минуту. Мост не читает cookies, пароли, сетевые токены или внутреннее состояние сайта. Он видит URL разрешённой вкладки и видимые элементы страницы. Наличие поля ввода — эвристика, а не доказательство входа.
4. Перезагрузите `http://127.0.0.1:8765/assistants.html` в том же браузере, где установлено расширение и открыты чаты. Расширение Edge не работает в отдельном встроенном браузере Codex.

## Обмен

Только явное нажатие пользователя резервирует один task ID и одну попытку. Глобально разрешено не больше одной незавершённой отправки, 4 попытки за 24 часа на провайдера, минимум 60 секунд между отправками. Резерв записывается до изменения чата, не возвращается после ошибки. Тексты задач не сохраняются расширением на диск; журнал попыток содержит метаданные, включая приватный URL чата, и остаётся только локальным.

Единственное пустое видимое поле получает текст с task ID. При наличии однозначной кнопки с подписью Send/Отправить выполняется один click. Структурный класс без подписи недостаточен для отправки, в том числе в текущем интерфейсе DeepSeek: остаётся черновик и требуется ручное действие в чате. Новый URL во время действия, CAPTCHA, лимит, ошибка, неоднозначный редактор или непустой черновик не приводят к повтору. Нажатие кнопки не считается подтверждением принятия запроса.

Для DeepSeek локальная панель до 5 минут проверяет только новый видимый `.ds-assistant-message-main-content` относительно счётчика до отправки. Новый текст должен стабилизироваться не менее 8 секунд; результат **captured_unconfirmed** требует сверки человеком. Пауза генерации может выглядеть как завершение, поэтому автоматического присвоения готовности нет. Для других платформ выделите ответ на странице и нажмите «Прочитать выделенный ответ» либо вставьте его вручную. Выделение может содержать любой текст; пользователь подтверждает принадлежность и полноту. Подтверждение полноты не является научной валидацией.

Материал сохраняется через существующий `/api/studio/save`, с CSRF из `/api/session` при наличии, выбранным проектом, idempotency key и статусом `unreviewed`. Приватные chat URL запрещено помещать в публичный репозиторий: экспорт предназначен только для личного хранения.

## Границы

Нет фоновой рассылки заданий, чтения вкладок за пределами разрешённых провайдеров, автоматической смены аккаунтов, обхода CAPTCHA/квот, установки плагинов по модельному тексту или платного fallback. Отмена разрешения закрывает новые команды. Ожидающая отправка и журнал резервов сохраняются после перезапуска браузера; только явное подтверждение проверки чата снимает блокировку ожидания. Ответ-кандидат хранится лишь в сессионной памяти, а не долговременном журнале расширения. Веб-приложение само по себе не может сканировать чужие вкладки; нужен этот явно установленный компонент. При выключенном ПК он не работает. Доступность адресов по мобильному интернету не гарантируется.

## Проверки

Проверки: `node --test browser-extension/policy.test.mjs browser-extension/bridge.test.mjs` в облачном CI. Они проверяют границы URL, идентификаторов, резервирования, конкурирующей отправки, неопределённого сбоя и отозванных прав с mock браузером, а не реальные ответы моделей. Для live acceptance: (1) без разрешений 0 кандидатов; (2) выдать один host grant; (3) увидеть эвристику, а не authenticated=true; (4) подготовить одно несекретное задание; (5) проверить ровно одно сообщение в чате; (6) проверить кандидат/выделение и сохранить в проект; (7) отозвать разрешение и убедиться, что доступ закрыт. CAPTCHA, платные режимы и неизвестные действия не подтверждать автоматически.
