# P0/Nanits — инкрементальное объединение цифровых стендов v0.41

Дата: 9 октября 2026. Продолжение пакета v0.40 из пользовательской Research Library. Исходный v0.40 сохранён без изменения внутри `baseline_v40/`. Добавлены `geometry_v1/` (сохранение площади одного виртуального носителя), `integration/bridge_v41.py` (программное соединение виртуальных сигналов и запретного мониторингового автомата) и тесты перекрёстной проверки.

## Что проверено

1. Исходный v0.40: 25 модульных тестов PASS при независимом запуске из восстановленного архива.
2. Новый геометрический surrogate: 8 тестов PASS.
3. Межмодельное соединение v0.41: 5 дополнительных тестов, в том числе 7 совместных аварийных сценариев, в которых обе цепи блокируются с 18-го шага; первый STOP не снимается, физического разрешения нет.
4. Модель виртуальной геометрии нормирована; площадь сохраняется аналитически. Это не модель сосудов, нейронов, актиномицетов, выращивания органов или медицинской пригодности трансплантата.

## Запуск

```bash
python -m unittest discover -s tests -v
PYTHONPATH=geometry_v1 python -m unittest discover -s geometry_v1/tests -v
cd baseline_v40 && python -m unittest discover -s tests -v && cd ..
python run_v41.py
```

`results/summary_v41.json` содержит обобщённые верифицируемые программные результаты; по каждому сценарию — `results/<scenario>_bridge.json`. Все команды исходного монитора ограничены `SIMULATED_SIGNAL_NOOP`, все команды геометрии — `SIM_ONLY/VIRTUAL_LATTICE`. Между ними нет перехода к живым бактериям или лабораторным приборам. Никакие реальные входы датчиков или аппаратное I/O не подключены. Нет API, выдающего DNA/RNA, лабораторные рецептуры или инструкции.

## Ограничения и экспериментальная интерпретация

Показано только свойство программной композиции: при возникновении заранее внесённой ошибки оба независимых по коду симуляционных механизма переходят в аварийное состояние. Их несвязанные искусственные показатели и произвольные пороги не являются независимыми биологическими сенсорами. Искажение общей причины, false negative вне набора fixtures, domain shift и неопределённость реальных тканей не устранены. v0.41 не предназначен для in vivo испытаний.

Состав документов и научная доказательность см. `baseline_v40/evidence/evidence_ledger_v40.json`, `new_evidence_v41.json`.
