Протокол `examples/brain_workflow_run.json` проверяет автоматическое продвижение координатором: HTTP-клиент только читает состояние. Повторный tick не размножает события. Два workers работают на одной физической машине; разные машины не проверялись.

15 тестов Brain покрывают фактическое исполнение, происхождение, сохранение, память public/internal, идемпотентность и восстановление после сбоев постановки и отмены. Четыре теста интерфейсов проверяют HTTP, MCP и параметры. Чрезмерное целое JSON возвращает ошибку входа без переполнения при преобразовании к float.

KAN проверена конечными разностями по всем параметрам обоих слоёв трёх базисов; изменение тестовых ответов не влияет на обученные веса. Независимое ревью градиентов дало максимальное расхождение 6.7e-11. Кортикальная модель проверена на изменение связей при обучении, неизменность обученного состояния при тесте, абляцию ёмкости и Markov-контроли.

После ревью исправлены переполнение метрики, сохранение намерения отмены перед отдельными транзакциями очереди, предел длины вопроса и отображение отменённых до постановки ветвей. Дополнительно исправлена валидация чрезмерных целых параметров и повторён полный набор. Предварительный успешный прогон: `docs/history/validation_v08_initial_attempt.json`; окончательный: `data/validation_results.json`.

Протоколы каталогов и клиентского обмена версии 0.7 сохранены с прежними датами и областью проверки. Живой поиск для версии 0.8 не повторялся. Новые сценарии не создавали аккаунтов, не привлекали внешних агентов, не использовали LLM, QPU и геномы людей.

Лимиты CPU/RAM POSIX worker не превращают Python в защищённую среду для чужого кода. Время относится к этому окружению. Проверка хешей предполагает доверенных workers; это не аттестация произвольного удалённого исполнителя. Программные проверки не являются биологической или клинической валидацией.
