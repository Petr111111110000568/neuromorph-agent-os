# P0/Nanits — evidence gate v1.0 (09.10.2026)

**Назначение:** дополнительный, независимый от предыдущего цифрового стенда модуль проверки структуры открытых научных свидетельств и математической симуляции отказобезопасного контура. Реализация не модифицирует предыдущие компоненты NeuroMorf и не соединяется с приборами.

## Проверяемые свойства

- 8 реестровых записей с DOI/публичной ссылкой, границами доказательств, отрицательными сведениями, безопасным следующим вычислительным шагом.
- Не повышает `PROGRAM`, `PATENT` и `UNVERIFIED` до экспериментально показанных результатов.
- Допускает только сообщения с целью `virtual_model` и командами `READ_STATE` или `SIMULATED_TICK`; никаких сетевых, файловых или аппаратных обработчиков команд нет.
- В виртуальной модели сохраняет 9 условных единиц, предел фазы 3, блокирует потерю последовательности, повтор команды и неопределённость больше 0.20 (это тестовый *безразмерный* порог, НЕ биомедицинский параметр).
- Выдаёт SHA-256 квитанции; это **не** подпись и **не** неизменяемый журнал.

## Запуск

Из корня проекта:

```sh
python -m unittest discover -s tests -p test_p0_evidence_gate.py -v
python -m p0_evidence_gate.gate p0_evidence_gate/evidence_2026-10-09.json --demo
```

Вывод `--demo` — JSON с контрольной суммой реестра и тремя **исключительно синтетическими** моделируемыми операциями. Он пригоден для загрузки в аналитические программы/виртуальные дашборды как JSON. Он **не предназначен** для биолабораторного или медицинского оборудования, не содержит последовательностей ДНК/РНК и инструкций для изменения организмов.

## Проверка первичных результатов

- [Lancet 2026, генетически модифицированная свиная почка](https://doi.org/10.1016/S0140-6736(26)01295-X) — 271 день без диализа у одного пациента, позднее повреждение трансплантата.
- [Nature Biomedical Engineering 2025, органоиды почки в перфузируемом свином трансплантате](https://doi.org/10.1038/s41551-025-01542-1) — обнаружение клеток через 24–48 часов, без доказательства полноценного нового органа.
- [Nature Communications 2025, беспроводное считывание бактериального сенсора](https://doi.org/10.1038/s41467-025-65416-5) — работа в тканевом фантоме на глубине 25 мм, не in vivo.
- [Process Biochemistry 2026, Streptomyces и биоэлектрохимия](https://doi.org/10.1016/j.procbio.2026.05.012) — физиологические эффекты in vitro, не органогенез.
- [Nature Biotechnology 2026, e-COSENS](https://doi.org/10.1038/s41587-026-03075-7) — лабораторный биоэлектронный сенсор, не имплантируемый трансформатор тканей.
- [OpenAI / Ginkgo Bioworks 2026](https://openai.com/index/gpt-5-lowers-protein-synthesis-cost/) — работавший роботизированный контур бесклеточного синтеза белка, а не актиномицетный симбионт.
- [ARPA-H FRONT](https://arpa-h.gov/news-and-events/front-program-selects-performer-team) — государственная исследовательская программа, не экспериментально завершённый продукт.
- [ARPA-H PRINT](https://arpa-h.gov/news-and-events/arpa-h-awards-teams-set-bioprint-universally-matched-organs-demand) — объявлены пять команд биопечати органов, без подтверждения создания готового органа в этой новости.
