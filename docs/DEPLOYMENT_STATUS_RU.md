## Как взаимодействовать

- **Задачи:** [Issues](https://github.com/Petr111111110000568/neuromorph-agent-os/issues). Первая конкретная работа — [независимая validation-выборка KAN/MLP](https://github.com/Petr111111110000568/neuromorph-agent-os/issues/1).
- **Результаты работы:** [Pull requests](https://github.com/Petr111111110000568/neuromorph-agent-os/pulls). AI-сопровождающий использует префикс `[AI-maintainer]`, работает в отдельной ветке и не сливает изменения.
- **Регулярный поиск и журналы:** [Actions](https://github.com/Petr111111110000568/neuromorph-agent-os/actions). GitHub-цикл запланирован ежедневно на 06:23 UTC и доступен для ручного запуска. Отключение: repository variable `AUTONOMY_ENABLED=false`.
- **Локальные эксперименты:** запустить `start.cmd` или `sh start.sh`, затем открыть `http://127.0.0.1:8765/brain.html`.

Ежедневный ChatGPT-сопровождающий пользуется подключением GitHub в аккаунте владельца. Он не является частью исполняемого кода репозитория и не переносится автоматически в чужой fork. Его можно приостановить в задачах ChatGPT. Один цикл ограничен небольшой задачей и одним draft PR; если проверочное исполнение недоступно, допускается конкретное улучшение документации либо Issue с честным статусом проверки.

Для дополнительных вызовов OpenAI/Anthropic настройте Repository Secrets и Variables по `docs/GITHUB_AUTOMATION_RU.md`. Ключи не следует отправлять в Issues или чат. Подключение провайдера само по себе не выдаёт произвольным найденным агентам доступ к коду: оператор внешнего агента участвует через PR или отдельный согласованный протокол федерации.

GitHub Models не используется: сервис закрыт 30 июля 2026 года, что подтверждено [официальной документацией](https://docs.github.com/en/github-models). Наличие расписания, успешный поиск или HTTP-ответ не являются научным подтверждением и не означают реализации биологических изменений.
