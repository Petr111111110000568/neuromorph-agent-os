# Работа ночью без включённого ПК

Облачный `continuous.yml` вызывает закреплённый Qwen Space, сохраняет резерв до вызова и результат в `autonomy/continuous`. Компьютер, Colab и квота Codex ему не нужны. Бесплатный провайдер может отказать; при отказе действует сохраняемый cooldown, а не обход ограничения. Общий лимит всех ролей — не более четырёх попыток за 24 часа и не чаще одной за шесть часов. Расписание запускается в 02:17, 08:17, 14:17, 20:17 UTC; GitHub может задерживать scheduled jobs.

`council-health.yml` независимо проверяет журнал в 02:52, 08:52, 14:52, 20:52 UTC и по ручному запуску. Он имеет только чтение репозитория, не вызывает моделей, не сбрасывает лимиты и не исполняет код из ветки предложений. Отчёты `receipt.json` и `report.md` находятся в артефакте `council-health-<run_id>` и сохраняются 14 дней. Незавершённый резерв, блокировка провайдера, отсутствие успешных ответов, некорректный журнал или просрочка более 18 часов дают `degraded`. Успешный workflow не означает исправность всех сервисов: ориентироваться нужно на receipt.

Доступные без ПК механизмы различаются: GitHub выполняет текущий Qwen-цикл; SourceCraft получает зеркало двух веток; Kimi завершил первый собственный облачный раунд COUNCIL-2026-09-26-01 в видимом чате и имеет сохранённое ежедневное расписание K3 на 07:00 по интерфейсу до 31 октября. Часовой пояс расписания отдельно не подтверждён. Первый успех не гарантирует доступность будущей бесплатной квоты. Web-чаты DeepSeek/Qwen и Алиса требуют работающего авторизованного контроллера; независимый облачный доступ к этим аккаунтам не настроен. HF publisher ждёт секрет записи. Code Assistant SourceCraft отвечает в чате, но два нативных AI-job завершились ошибкой запуска; роли этих сервисов нельзя считать действующими только по карточке.

Истечение лимита Codex прекращает работу этого контроллера. Облачный отчёт продолжит сохраняться без него; Codex сможет прочитать отчёт при следующем доступном запуске. Непрерывное наблюдение самим Codex во время недоступности его модели не заявляется.
