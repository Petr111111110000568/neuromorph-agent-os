# Расходы 0 и реальный объём автоматизации

Политика пользователя: только бесплатные ресурсы, дополнительные расходы 0. Проверено 25 сентября 2026.

## Применение

config/resource_policy.json — строгая схема: schema_version=1, daily_spend_limit_usd=0, paid_model_calls_allowed=false, public_catalog_reads_allowed=true. Поддержка ненулевого бюджета намеренно отсутствует: счётчика денежных расходов нет. Отсутствующий файл равнозначен нулевому бюджету, неверные/неизвестные поля отклоняются.

Политику проверяют autonomy.run_cycle и HarnessRegistry.run; публичные CLI, HTTP и MCP идут через эти входы. Сервер показывает запрошенное и фактически разрешённое состояние отдельно. Env-флаг или API-ключ не обходят запрет. Проверки с поддельным транспортом подтверждают, что live transport не вызывается.

Чтение четырёх публичных каталогов остаётся доступным без ключей. Локальный loopback protocol test использует синтетический ответ и не является inference. Низкоуровневые Python-функции транспорта служат реализацией/тестовым интерфейсом, не изоляцией от произвольного исполнения Python оператором.

## Что независимо от OpenAI

Существующий ежедневный GitHub workflow работает без Codex/ChatGPT. В текущем изменении из него убран шаг передачи OpenAI/Anthropic Secrets: всегда выбран provider none. До слияния изменения работает прежняя удалённая версия; по проверенному запуску 25 сентября и там модельный шаг был выключен.

Python-программа, запущенная пользователем, не использует недельный лимит Codex. Её задачи — discovery, правила подготовки плана, сохранение истории и разрешённые локальные вычисления. Это не заменяет внешнюю LLM и не подтверждает научные гипотезы.

Бесплатный веб-доступ Qwen/DeepSeek — отдельный интерфейс, не API-ключ. Автоматизация через текущую сессию Codex всё ещё зависит от Codex, открытого браузера и доступности сайта. Поэтому её нельзя выдавать за независимую непрерывную службу после исчерпания квоты.

## История и ограничения

--history-db включает транзакционный SQLite-журнал: first_seen/last_seen, публичная provenance, revision/license, стабильный digest содержимого. Время получения не меняет digest. Отсутствие карточки в частичном ответе не удаляет ресурс. Изменение digest при том же времени наблюдения отклоняет весь цикл; старое наблюдение не откатывает текущую карточку.

Лимиты: 2000 ресурсов, 10000 наблюдений изменений, 2000 запусков, 256 MiB. Удаление по лимиту — retention, не удаление источника из интернета. Первое наблюдение после истечения хранения не доказывает, что источник никогда не встречался. Идемпотентность гарантируется только для сохранённого окна.

Существующий неизвестный SQLite-файл, ссылки/reparse/hardlink и preexisting journal/wal/shm отклоняются. Аварийный hot journal требует явного восстановления оператором. Файлы cycle.json/proposal.json/report.md и SQLite не являются общей транзакцией. Ошибка истории возвращает CLI error, даже если последний отчёт уже записан.

GitHub artifacts хранятся 14 дней и текущий workflow не восстанавливает SQLite между runners. Локальный журнал сохраняется на диске. Добавление облачного хранилища требует отдельной проверки бесплатной квоты; cache/artifact нельзя считать безлимитными.
