# Студия НИОКР

`/studio.html` объединяет проекты, вопросы, критерии результата, протоколы, канбан, источники, материалы и журнал изменений. Хранение — серверная SQLite; создание имеет ключ идемпотентности, редактирование требует текущую версию и возвращает409 при конфликте. Отметки reviewed/tested принадлежат автору записи и не являются независимой научной валидацией. Запись задачи в канбан не запускает модель.

`/assistants.html` — отдельный браузерный канал для выбранных пользователем чатов. Установка компонента, выдача доступа, обнаружение вкладки, проверка редактора, отправка и возврат текста имеют разные статусы. Сайт не получает browser cookies. Подписка на consumer chat не равна доступу к платному API или аренде вычислительной машины. Локальный браузерный канал требует работающего ПК.

Основные расчётные панели `/brain.html`, `/network.html`, `/harnesses.html` сохранены. Облачный Qwen observer читает фактический публичный ledger, не инициирует новые попытки и не обходит его cooldown. JSON-экспорт содержит пользовательские материалы: размещать его публично можно только после отдельной проверки содержимого.

## Вход и размещение

По умолчанию сервер остаётся только loopback, под локальным пользователем ОС. Для облачного входа предусмотрен отдельный `python -m workbench.cloud_app`: только один заранее указанный владелец Яндекс ID, PKCE/state, серверные непрозрачные сессии, CSRF, закрытые API. [Контракт и переменные](CLOUD_AUTH_CONTRACT_RU.md). Секреты не задаются через UI студии, Git или Docker build args. Конфигурация отсутствует — процесс завершается до bind.

`deploy/cloud/Dockerfile` — переносимая упаковка для одного процесса за HTTPS reverse proxy и постоянного локального volume `/state`. Сервисный HTTP-порт должен быть доступен только proxy. Он не подходит для эфемерной файловой системы Yandex Serverless Containers или нескольких реплик с общей SQLite. Для serverless требуется отдельный транзакционный адаптер YDB/PostgreSQL. Dockerfile не является доказательством выполненного развёртывания, OAuth-входа или сохранности данных в конкретном облаке.

Опциональный снимок в браузере включается пользователем; это локальная копия для чтения на уже открытой странице. Ключи и сессионные cookies в снимок не входят. Есть удаление копии и экспорт; перезагрузка без сети не гарантируется, Service Worker не установлен.

## Исследованные интерфейсы

Из AutoGen Studio взята структура команда→сессия→результат; из Langflow — связь проекта и отдельной сессии; из Open WebUI — единая рабочая область с материалами и подключениями. Это собственный интерфейс над текущими API, не установка всех этих платформ.

- [AutoGen](https://github.com/microsoft/autogen) находится в maintenance mode. [Studio](https://microsoft.github.io/autogen/stable/user-guide/autogenstudio-user-guide/index.html) — исследовательский прототип, не готовая защищённая облачная система.
- [Microsoft Agent Framework DevUI](https://learn.microsoft.com/en-us/agent-framework/devui/) — среда разработки; зрелость SDK не переносится автоматически на её публичное размещение.
- [Langflow Playground](https://docs.langflow.org/concepts-playground) разделяет flow и session. [Auth](https://docs.langflow.org/api-keys-and-authentication) требует отдельной настройки.
- [Open WebUI](https://docs.openwebui.com/features/) предоставляет workspace/knowledge/tools; model preset не является новым независимым модельным провайдером.

## Российское размещение и мобильный доступ

Проверено 26.09.2026. [SourceCraft Sites](https://sourcecraft.dev/portal/docs/ru/sourcecraft/concepts/sites) — бесплатная статика, без backend и с `worker-src 'none'`; PWA на этом хостинге не обещается. [VibeCraft](https://sourcecraft.dev/portal/docs/ru/vibecraft/) создаёт fullstack-код, но [публикация](https://sourcecraft.dev/portal/docs/ru/vibecraft/operations/deploy) требует платёжного аккаунта Yandex Cloud. [Встроенный Яндекс ID](https://sourcecraft.dev/portal/docs/ru/vibecraft/operations/connect-yandex-id) требует собственного домена и платной подписки. Это не обязательное требование отдельного собственного OAuth-adapter, но его регистрацию и callback всё равно нужно настроить.

[Yandex free tier](https://yandex.cloud/ru/docs/billing/concepts/serverless-free-tier) содержит бесплатные месячные объёмы, после них применяется тарификация. [Budget](https://yandex.cloud/ru/docs/billing/concepts/budget) уведомляет, а не останавливает расходы. Поэтому deployment с гарантированным нулевым расходом не заявлен только на основании квот. Новые условия SourceCraft с1октября нельзя выдавать за уже действующие 26сентября.

Российский хостинг или домен Яндекса сам по себе не доказывает доступность приложения по белым спискам оператора. Проверять нужно конкретный URL и цепочку входа в нужной мобильной сети. Внешние CDN/шрифты в интерфейсе не используются; при сетевом отказе результаты не подменяются демонстрацией успеха.
