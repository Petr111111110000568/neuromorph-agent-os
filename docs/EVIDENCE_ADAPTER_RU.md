# Адаптер аннотаций Europe PMC · v0.6

Адаптер действительно запрашивает публичные библиографические записи и доступные аннотации через Europe PMC REST API. Его результат — материал для первичного разбора источников: DOI/ссылка, короткая выдержка, контрольная сумма текста и объяснимые совпадения терминов. Проверку истинности выводов или применимости к взрослому организму он не выполняет.

## Интерфейс

```python
from workbench.society.evidence import collect

result = collect(
    "machine learning reproducibility benchmark",
    limit=2,
    offline=False,
)
```

`collect(query, limit=5, offline=False, root=None)` возвращает:

| Поле | Смысл |
|---|---|
| `query` | Запрос после нормализации пробелов |
| `mode` | `public_abstract_triage` либо `offline_index` |
| `items` | До 8 записей после удаления повторов DOI |
| `errors` | Структурированные ошибки без содержимого ответа и внутренних деталей сети |
| `requests` | Число попыток обращения к провайдеру: 1 online, 0 offline |

Запись содержит `id`, `title`, `url`, `doi`, `abstract_available`, `abstract_sha256`, `indicators`, `indicator_matches`, `provenance`, `limitations`. При наличии аннотации добавляется `excerpt` не длиннее 12 слов. Ссылка строится только на `doi.org` или `europepmc.org`; произвольные URL из ответа не переходятся. При повторе DOI предпочтение получает запись с доступной аннотацией.

Полный текст аннотации не возвращается и не сохраняется адаптером. SHA-256 вычисляется из UTF-8 после удаления HTML и нормализации пробелов. Он связывает результат с полученным текстом; сам по себе хеш не доказывает научную достоверность и не гарантирует, что провайдер впоследствии вернёт тот же текст.

## Лексические индикаторы

| Индикатор | Примеры словаря |
|---|---|
| `in_vitro` | `in vitro`, `cell culture`, `organoid` |
| `animal` | `mouse`, `mice`, `murine`, `rat`, `zebrafish` |
| `human` | `human`, `patient`, `clinical trial` |
| `computational` | `simulation`, `in silico`, `machine learning`, `computational model` |
| `systematic_review` | `systematic review`, `meta-analysis` |
| `randomized` | `randomized`, `randomised` |
| `negation_present` | `no`, `not`, `without`, `lack`, `lacking` |

Полный фиксированный словарь находится в `INDICATOR_TERMS`; `indicator_matches` показывает конкретные совпадения. Поиск учитывает границы слов и регистр. Словарь английский: отсутствие индикатора не означает отсутствия явления, а описание работы на другом языке может не дать совпадений. Фраза об отсутствии данных на людях способна дать одновременно `human` и `negation_present`. Отрицание не связывается алгоритмом с конкретным утверждением. Это не классификатор дизайна исследования, оценка качества или автоматический обзор доказательств.

## Получение данных и ограничения

- Единственный сетевой endpoint: `https://www.ebi.ac.uk/europepmc/webservices/rest/search`, параметры `format=json`, `resultType=core`, `pageSize=limit`. [Справочная страница Europe PMC REST API](https://europepmc.org/RestfulWebService).
- Запрос: 1–2000 символов; лимит: целое число 1–8. Неправильные входы вызывают `ValueError`.
- Размер JSON: до 1 000 000 байт; аннотации: до 100 000 символов на запись. Неизвестная структура, нечисловая длина, превышение лимитов, не-JSON, сжатый ответ и неограниченные числовые значения отклоняются.
- Перенаправления запрещены. HTTPS использует стандартную проверку сертификатов. Системные настройки транспортного proxy учитываются: в управляемой рабочей среде proxy может быть необходим для выхода в интернет.
- Таймаут отдельного сетевого ожидания: 12 секунд. Бюджет чтения: 24 секунды от начала запроса, проверяется между порциями и после чтения. Это не жёсткая гарантия wall-clock для системного DNS/зависшего транспорта; внешние ограничения worker-процесса остаются отдельным уровнем.
- Автоматических повторов и переходов к другим провайдерам нет. HTTP/сетевая ошибка отражается в `errors`, а `requests=1` обозначает попытку, а не успешное получение.
- HTML очищается; содержимое `script`, `style`, `template` удаляется. Текст источника обрабатывается как данные, без загрузки вложений, команд или исполнения кода.
- Доступны только публичные данные. Запрос online отправляется внешнему провайдеру. Классификацию данных и разрешение отправки проверяет вызывающая платформа; сам низкоуровневый адаптер не обнаруживает персональные или геномные данные внутри произвольной строки.

Режим offline ранжирует только упакованный локальный каталог. Для всех результатов `abstract_available=false`, `abstract_sha256=null`, `retrieval_kind=local_index_only`. Время в `retrieved_at` обозначает чтение каталога в этой операции, не время загрузки оригинальной статьи. Каталог также содержит описания инструментов; совпадение не превращает такую запись в публикацию.

Это проверка транспорта, формата и обработки данных, а не качества этих исследований. Первоначальная проба с отключённым системным proxy вернула `network_error`; штатный транспорт с proxy успешно отработал, поэтому итоговый адаптер сохраняет настройки среды.

Детерминированные проверки:

```bash
python3 -m unittest discover -s tests -p test_evidence.py -v
```

12 тестов охватывают HTML/хеш/длину выдержки, отсутствие аннотаций, отрицания и границы слов, дубликаты DOI, неподходящие строки/контейнеры, лимиты, offline без сети, типы входов, ошибки провайдера без утечки деталей, фиксированный endpoint, запрет redirect, неправильные MIME/encoding/JSON, переполнение тела и истечение бюджета чтения.

Отдельный online-запуск текущей версии нужен для проверки доступности сети на другой машине: состояние провайдера и исходные публикации могут измениться.
