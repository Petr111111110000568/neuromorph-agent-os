# Локальный тандем OpenClaw и Hermes

Один конечный проход: **OpenClaw составляет план → Hermes ищет контрпример → OpenClaw уточняет план**. Для всех трёх ролей настроена одна локальная Qwen3-14B-Q4_K_M через закреплённый llama.cpp. Факт завершения каждого запуска подтверждает его отдельная квитанция. Это два настоящих agent harness, но одна модель; согласие не является независимым научным подтверждением.

## Что делает интеграция

- Использует OpenClaw 2026.9.6 из точного npm lock и Hermes SDK из commit `54fb5a42e8ecf2bf0326f7bd829a292ee0965451`. Облачный профиль Hermes 0.21.5 остаётся отдельным.
- Создаёт отдельные временные профили. Не использует сохранённые аккаунты Desktop/Companion, их `.env`, внешние API-ключи, автоматически устанавливаемые skills или fallback.
- Передаёт предыдущие ответы как недоверенные данные с хешами. Сохраняет исходный вопрос, роли, версии, хеши входа/результатов, резерв и итоговую квитанцию в `<data_dir>/tandem`.
- До локального inference расходует долговечный резерв. Не больше трёх вызовов на идентичность задачи. Повтор того же `task_id` возвращает сохранённую квитанцию. Неопределённое завершение не вызывает автоматической повторной отправки.
- Использует общий с `/offline.html` файл блокировки модели. Два контроллера не должны одновременно занимать GPU одним и тем же экземпляром.
- Временный HTTP endpoint слушает только `127.0.0.1`, требует случайный Bearer, ограничивает схему/размер и допускает ровно один no-tools completion за этап. Секрет не записывается в конфигурацию и не передаётся в argv.

Профиль выполняет исследовательское планирование и текстовую рецензию. Модельные предложения не исполняются, не изменяют проект и не утверждают собственные права. Подключение CPU-обработчика M02 требует отдельного принятого контракта и проверки результата.

## Запуск

Оператор создаёт локальный JSON с абсолютными путями (не публикует его):

```json
{
  "schema_version": 1,
  "model_root": "/absolute/accepted-runtime-with-model",
  "data_dir": "/absolute/shared-platform-state",
  "node": "/absolute/node",
  "openclaw_package": "/absolute/node_modules/openclaw",
  "hermes_python": "/absolute/hermes-dependency-venv/bin/python",
  "hermes_source": "/absolute/hermes-source",
  "git": "/absolute/git"
}
```

`openclaw_package/neuromorph-installed-manifest.json` содержит принятые SHA256 Node, package.json и entrypoint. Зависимости устанавливаются из `config/openclaw-local/package-lock.json` с `npm ci --ignore-scripts`. Hermes проверяет source commit, отсутствие изменений tracked файлов и отдельный реестр хешей. Для Hermes используется Python 3.14 с установленными зависимостями; голый bundled Python Desktop не обязательно содержит их.

```text
python -I scripts/run_local_tandem.py --profiles /absolute/local-profiles.json --task-id TANDEM-001 --question-file /absolute/public-task.txt --public-data-confirmed
```

Вопрос — публичное описание задачи, без credentials или частных медицинских данных. Идентификатор не переиспользуется для изменённого входа; сбой не исправляют сменой ключа ради обхода резерва. Следующий запуск допускается после установленной причины и отдельной новой задачи.

## Ограничения и проверка

Локальный контекст фактически 8192, выход до 512 токенов на этап. Hermes upstream требует 64K даже для пустого toolset; адаптер явно ослабляет только эту проверку для данного `custom`/loopback/no-tools/8192 маршрута. Загрузка dotenv отключена до импорта агента. Это объявленные адаптации, а не заявление о штатной поддержке 64K. Исходники пользовательской установки не изменяются.

Python I/O guard, запрет инструментов и Windows Job не являются полноценной файловой/сетевой песочницей. Непроверенные расширения и произвольный сгенерированный код здесь не исполняются. OpenClaw `OPENCLAW_OFFLINE=1` отключает автозагрузку вспомогательных бинарников, но сам по себе не блокирует весь интернет.

`tandem-harness.yml` проверяет **настоящие CLI/SDK** с детерминированным локальным ответом; это проверка транспорта без inference. Core/portability проверяют бюджет, блокировки, дубликаты, отказы и протокол. Фактический цикл с Qwen имеет отдельную квитанцию; успешный fixture не выдаётся за ответ модели.

Первое окружение — Windows/Vulkan с уже установленной Qwen. Облачный protocol fixture работает без весов на Linux. Наличие переносимых unit tests не доказывает работоспособность GPU-профиля на других ПК. Работа локального тандема зависит от включённого ПК; это не постоянный облачный агент.
