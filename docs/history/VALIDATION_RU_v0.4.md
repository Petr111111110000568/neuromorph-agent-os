# Проверка Meta-Harness v0.4

Дата: 18 сентября 2026. Среда исполнения: Linux, Python 3.12.14. Это проверка программной поставки; биологическая эффективность не испытывалась.

## Выполнено

| Проверка | Результат | Что подтверждает |
|---|---|---|
| `python -m unittest discover -s tests -v` | 21 из 21 успешно | Математические инварианты, реальные дочерние процессы, база, API и MCP |
| `python -m workbench doctor` | Целостность builtin-кода и журнала подтверждена | 4 встроенных модуля и доступность локального runtime |
| `python scripts/smoke_release.py` | Все 5 этапов успешно | HTTP-выдача интерфейса, выбор источника → совет → вычисление → экспорт → восстановление базы |
| `node --check web/app.js` | Успешно | Синтаксическая корректность JS |
| Статическая проверка HTML/JS | Уникальные ID, статические ссылки на элементы разрешаются | Базовая согласованность файлов интерфейса |
| Личный навык `meta-harness-research` | Установлен; валидация и отдельный сценарий применения успешны | Настройка повторяемой процедуры работы в аккаунте |
| GitHub и Context7 | Реальные read-запросы успешны | Работоспособность конкретных подключений при проверке |

## Содержательные проверки

- Квантовая CPU-модель: нулевой угол, распределение состояния Белла, предельное деполяризующее смешивание, воспроизводимость выборки. QPU не использовался.
- Динамическая модель: нулевое возмущение даёт базовую траекторию; диффузионная связь сохраняет среднее, меняя локальный отклик. Абстрактные единицы не интерпретируются как тканевые измерения.
- ML: удержанная тестовая выборка не используется при подборе коэффициентов; RBF сравнивается с линейным baseline на синтетической функции. Сохранён пример фактического запуска `examples/verified_workflow.json`.
- Восстановление: источник, совет, расчёт и процесс остаются доступны после закрытия и открытия SQLite.
- Целостность: изменение записи, отсутствие обязательного хеша или замена кода обнаруживаются. Журнал не имеет внешней подписи и не защищает от полного согласованного переписывания.
- Ошибки: нечисловые/бесконечные значения, неверные URL, неизвестные модули и источники, избыточная вложенность JSON отклоняются. Таймаут дочернего процесса сохраняется как неуспешный расчёт.
- HTTP: проверены Host/Origin, попытки выхода за каталог и экспорт. MCP: отдельный процесс выполняет handshake, выдачу инструментов и реальный расчёт.

## Не проверено и не реализовано

Удалённый управляемый браузер отклонил `http://127.0.0.1:8765` с `net::ERR_BLOCKED_BY_CLIENT`. Поэтому визуальная проверка, клики по элементам и полноценный browser end-to-end тест не выполнены. Успех HTTP и статической проверки не заменяет проверку отображения.

Windows/macOS, многопользовательская работа, публичное размещение, нагрузка и длительная непрерывная эксплуатация не тестировались. `start.cmd` и `start.sh` предоставлены для запуска с установленным Python. Сервер предназначен для одного локального пользователя.

Восемь встроенных советников используют фиксированные правила. Проверка содержания научных статей по нажатию кнопки не выполняется; прикреплённые источники сохраняются как происхождение вопроса. Реальный LLM-провайдер, тяжёлые научные пакеты, GPU/QPU, очередь длительных заданий и лабораторное оборудование не подключены.

Ограничения ресурсов дочернего процесса не дают изоляцию недоверенного кода. Ядро допускает только закреплённые встроенные модули. Наличие bwrap в среде не считается изоляцией: создание namespace было отклонено.

Реестр содержит 45 изученных первичных источников и 1 запись видео, проверенную только по метаданным. Доступность сервисов и версии внешних проектов необходимо повторно проверять при фактическом подключении. Новый видеофайл не расшифрован, остальные ранее загруженные материалы в этой сборке повторно не исследовались.

Эти результаты подтверждают работоспособность ограниченного вычислительного цикла. Они не доказывают возможность ускоренной эволюции, омоложения, перестройки генома или управления целым взрослым организмом.
