## Что покрывают тесты

- Базовый v0.4-код: математические инварианты четырёх модулей, закреплённые хеши, реальные процессы, журнал, SQLite, HTTP и MCP.
- Очередь: гонка независимых процессов/соединений, атомарный claim, аренда и продление, истечение, повтор, лимит попыток, отмена, восстановление и отсутствие lease-секретов в публичных ответах.
- Кампании: реальные встроенные расчёты, лимиты, восстановление между итерациями, остановка, ошибки провайдеров, отклонение пустого результата, идемпотентное внесение метаданных.
- Частичная отправка: искусственно прерван второй commit; после перезапуска отмена находит первое задание по ключу и останавливает его. Это регрессионная проверка обнаруженного дефекта.
- Транспорт: фактические HTTP и TLS, аутентификация, запрет browser Origin, неверных полей, чрезмерного JSON и перенаправлений, ограниченные повторы, heartbeat и поздние результаты.
- Discovery: фиксированные провайдеры, дедупликация DOI, пределы ответа, ошибки формата, офлайн-ранжирование, невозможность объявить внешний найденный ресурс исполняемым адаптером.
- Accounts: повторные и параллельные заявки, сохранение, вычисляемые статусы, отклонение секретных полей, точный домен настройки и отсутствие значения credentials в базе/экспорте.

## Воспроизведение

Из каталога проекта:

```bash
python3 -m unittest discover -s tests -v
python3 scripts/demo_network.py
python3 scripts/verify_network.py
python3 scripts/verify_network.py --online --output online-check.json
```

Последняя команда отправляет фиксированный публичный тестовый вопрос в Europe PMC/Crossref. Выдача и время зависят от сети и состояния внешних API. Автотесты используют фиксированные ответы там, где проверяется разбор ошибок; это отдельно от фактического онлайн-прогона.

Сохранённые результаты: `examples/distributed_online_run.json`, `examples/distributed_offline_run.json`. Они содержат идентификаторы заданий, назначенные workers, события кампании, метаданные источников и хеши вычисления; не содержат токены hub/lease.

## Ограничения проверки

Несколько физических машин, внешняя сеть между узлами, облачное размещение, длительная нагрузка, Windows/macOS и работа после перезагрузки ОС не испытывались. Менеджер сервисов, backup, сертификаты и удалённые машины не предоставляются исходным архивом.

Браузерная и визуальная проверка интерфейса не выполнена. В этом окружении управляемый браузер ранее отклонил localhost с `net::ERR_BLOCKED_BY_CLIENT`; новые страницы проверены статически и через реальный HTTP API. Проверка API не равна тестированию кликов и отображения.

Нет независимой научной валидации найденных работ, интеграции тяжёлых биологических симуляторов, реального QPU, LLM-планировщика или лабораторного оборудования. Удалённые workers входят в доверенную группу; подтверждение происхождения результата не является аттестацией честности их машины.
