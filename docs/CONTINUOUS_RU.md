# Самостоятельный облачный цикл

`continuous.yml` выполняется в GitHub Actions четыре раза в сутки, без запущенного Codex, браузера и Colab. Один запуск ограничен восемью минутами и одной попыткой генерации. Нет недельного срока окончания; выключение — Repository Variable `CONTINUOUS_ENABLED=false` или Disable workflow. Это расписание платформы, а не гарантия непрерывной доступности бесплатного сервиса.

## Что происходит автоматически

1. Доверенный контроллер восстанавливает JSON по закреплённому commit ветки `autonomy/continuous` и резервирует попытку отдельным commit **до** запроса модели.
2. Отдельный процесс без токенов читает небольшие публичные каталоги и передаёт Qwen выдержку предыдущего ответа. Роли `author → reviewer → reviser` чередуются только после корректного структурированного результата. Это три роли одной модели Qwen, а не независимые модели или научная репликация.
3. Ответ проходит проверку схемы; Python разбирается синтаксически без выполнения. Контроллер записывает исследование и кодовое предложение в фиксированные файлы ветки. История Git сохраняет итерации; текущее состояние хранит последние 32 результата.
4. При временной ошибке применяется пауза от суток до недели. HTTP 429 не вызывает немедленных повторов. При обрыве процесса резерв остаётся в Git и выдерживается минимум сутки. Ошибки доступа/изменённый контракт блокируют этот модельный канал. При повреждении хранилища автоматического сброса нет.

Предел — одна попытка за шесть часов и не более четырёх за скользящие 24 часа. Повторный запуск того же workflow run не создаёт повторного модельного запроса. Изменения обычного кода в main не сбрасывают состояние. Одновременно разрешена только одна запись; конфликт не приводит к force-push.

Код предложений не запускается автоматически и не изменяет main. Автоматическая работа продолжается на собственной ветке, не ожидая merge. Синтаксическая проверка не доказывает корректность поведения: внедрение в основное ядро требует отдельной проверки. Старый семидневный cloud-review по умолчанию выключен, чтобы не создавать параллельные обращения к той же Space.

## Фактические подключения

Независимый runtime использует только публичный официальный Qwen Space с закреплённым контрактом. DeepSeek, Qwen web и Alice web могут участвовать через отдельный контроллер Codex, пока доступны его квота и авторизованные сессии; они не являются фоновыми API этого workflow. Antigravity заблокирован сервисом по региону. Эти ограничения не маскируются фиктивными ответами или доступом через cookies.

Hugging Face содержит публичный стартовый manifest и метаданные вкладов. Автоматическая запись из Actions туда пока не подключена: имеющийся inference-токен не предоставляет нужных прав записи. Независимое постоянное хранилище текущего цикла — GitHub. Секреты не пересылаются моделям; платный fallback отсутствует.

Workflow допускается только для данного публичного репозитория на стандартном `ubuntu-24.04`, при политике расходов 0. Отдельный запуск заканчивается по тайм-ауту; следующее выполнение запускает планировщик GitHub. Модель не может менять лимиты, доступ, расписание или команду запуска.
