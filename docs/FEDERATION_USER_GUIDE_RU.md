# Работа с исследовательской федерацией Meta-Harness 0.7.0

Цель прототипа — организовать проверяемый вклад внешнего исполнителя: от обнаружения возможностей до получения результата и выдачи доступа к разрешённой сводке. Программы других операторов выполняются в их собственном окружении. Обмен не устанавливает их код на координатор и не даёт им административного доступа.

## 1. Подготовьте координатор

Распакуйте проект. Нужен Python 3.11+. Все команды ниже выполняются из каталога проекта. В Windows используйте `start.cmd`, в Linux/macOS — `sh start.sh`; общий эквивалент:

```sh
python -m workbench local-network
```

Откройте **http://127.0.0.1:8765/federation.html**. Порт `8765` — локальная консоль, `8766` — доверенные workers, `8767` — шлюз участников. Стартовый запуск поднимает два worker-процесса. Ctrl+C завершает запущенные компоненты; данные остаются в `state/`.

Во втором терминале можно явно добавить пример предложения и собственную сводку проекта:

```sh
python -m workbench seed-exchange
```

Обновите страницу. Стартовая задача предлагает сравнить опубликованные оценки моделей клеточного состояния; за принятый вклад предусмотрены три неденежных кредита, а авторская методическая сводка стоит два. Это содержимое для первого пилота, а не доказательство уже выполненной научной работы.

Для другого каталога состояния ставьте общий параметр **перед** подкомандой: `python -m workbench --data-dir private/project-state local-network`. Во всех администраторских CLI-командах используйте тот же `--data-dir`, иначе откроется другая база.

## 2. Найдите кандидата

В разделе **«Поиск и кандидаты»** задайте публичную тему, например `research`, `genomics` или `dataset quality`. Выберите каталоги. По умолчанию используются локальные сведения. Включение **«Обращаться к публичным API»** отправляет запрос выбранным каталогам.

| Каталог | Что найдено | Что проверить отдельно |
|---|---|---|
| Agentverse | Карточка агента | Владелец, доступность, совместимый способ связи |
| Hugging Face models | Карточка модели | Лицензия, ресурсы запуска, научная пригодность; модель не принимает приглашения сама |
| Hugging Face datasets | Метаданные набора | Права доступа, состав данных, разрешённое использование |
| Official MCP Registry | Описание сервера инструмента | Лицензия, права, окружение; MCP-сервер не обязательно автономный агент |

CLI позволяет выполнить ограниченный поиск:

```sh
python -m workbench scout --query research --providers agentverse,huggingface_models,huggingface_datasets,mcp_registry --online --limit 3 --cycles 1
```

Для повторов доступны `--cycles` от 1 до 20 и `--interval` от 10 до 3600 секунд. Без `--online` сеть не используется. Кандидаты показывают заявленные возможности и происхождение; их наличие не означает вступления.

Раздел **«Проверить карточку агента по известному адресу»** принимает точный HTTPS URL JSON-карточки. Для реально известного Tor v3 onion URL укажите уже работающий локальный SOCKS5 proxy, например `127.0.0.1:9050`. Приложение не устанавливает Tor, не ищет неизвестные onion-адреса и не сканирует закрытые сети. При неуспехе Tor запрос не перенаправляется в clearnet. Подробнее — [контракт обнаружения](FEDERATION_DISCOVERY_RU.md).

## 3. Сформулируйте задачу и пользу участия

В **«Предложения участия»** укажите название, публичное описание, тип работы, критерии приёмки, награду и максимальное число результатов. Поддерживаются обзор литературы, проверка качества данных и воспроизведение метода.

Пример измеримой задачи по геномным исследованиям: сопоставить два опубликованных benchmark моделей клеточного состояния, указать разбиение по независимым донорам, простой baseline, метрики и ограничения переноса. Исполнитель получает публичную постановку и ссылки; личные геномы и медицинские записи не входят в обмен.

В **«Ресурсы для обмена»** добавьте собственную сводку: название, описание, текст, лицензию, стоимость и подтверждение прав передачи. `public` раскрывает метаданные в каталоге; `internal` скрывает подробные метаданные, а разрешённый текст выдаётся допущенному участнику после обмена и создания права. В обоих случаях содержимое не показывается публично. Подтверждайте права только на материалы, которыми действительно можете делиться.

В **«Приглашения и подключение»** выберите кандидата и доступное предложение. Кнопка **«Подготовить приглашение»** формирует черновик: какую задачу выполнить, что считается результатом и какой доступ можно получить. Прототип не отправляет текст и не регистрирует учётную запись во внешней платформе.

Потенциальный оператор оценивает свои затраты и принимает условия. Вознаграждение предусмотрено за принятый результат; время само по себе кредиты не начисляет. Платформа не обещает материалы, которых ещё нет в каталоге.

## 4. Выпустите одноразовое приглашение

После согласования участия скопируйте `offer_id` из карточки. На координаторе выполните:

```sh
python -m workbench invite --offer OFFER_ID --out private/invitation.json
```

Замените `OFFER_ID` реальным идентификатором. По умолчанию приглашение действует 24 часа в пределах срока предложения. Для срока один час добавьте `--expires 3600`. Повторно использовать приглашение нельзя. Существующий выходной файл не перезаписывается.

Файл содержит секрет. На POSIX он создаётся с правами `0600`; клиент требует владельца — текущего пользователя и отсутствие доступа группы/остальных. В Windows проверьте ACL средствами системы. Передайте файл оператору участника согласованным защищённым способом; не размещайте его в публичной карточке, репозитории или отчёте. Приложение не выполняет передачу автоматически.

Приглашение фиксирует предложение, срок и `terms_hash`. Токен допуска подтверждает владение приглашением; принадлежность исполнителя названной организации этим не удостоверяется.

## 5. Присоедините программу участника

Следующие команды выполняются на той же машине для проверки. Для другого компьютера сначала настройте HTTPS-шлюз по разделу 9 и замените URL. `127.0.0.1` означает локальную машину участника, а не удалённый координатор.

Просмотрите условия и каталог:

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 offers
python -m workbench.federation.client --url http://127.0.0.1:8767 resources
```

После принятия условий:

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json join --name research-agent --capabilities literature_review,method_reproduction --invitation-file private/invitation.json --accept-terms
```

`--capabilities` — список заявляемых возможностей через запятую. Клиент считывает `terms_hash` из приглашения, передаёт явное согласие и сохраняет новый рабочий credential в `private/member.json`. Токен не печатается. Членство привязано к этому предложению; другая задача требует отдельного допуска. Credential-файл также создаётся однократно с правами `0600` на POSIX и связан с конкретным URL шлюза.

Проверьте членство и баланс:

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json member
```

Самостоятельный агент может вызывать `ParticipantClient` из `workbench.federation.client` или документированный HTTP API. Он сам выбирает разрешённый метод исследования и формирует результат в своём окружении. Универсального адаптера ко всем внешним платформам в этой версии нет; этот клиент — конкретная точка подключения.

## 6. Возьмите работу и сдайте результат

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json claim OFFER_ID --idempotency-key first-contribution
```

Запомните `assignment_id` и `lease_expires_at` из ответа. Повтор с тем же ключом возвращает прежнюю попытку. После истечения аренды для новой попытки нужен новый ключ и свободное место. Аренда не продлевается автоматически.

Исполнитель создаёт `result.json` с тремя обязательными полями. Ниже форма результата, требующая заполнения фактической работой; пример URL нужно заменить проверенным первичным источником:

```json
{
  "result": {
    "kind": "literature_review",
    "summary": "Заполнить выводом проведённого анализа",
    "comparisons": []
  },
  "source_refs": ["https://example.org/replace-with-primary-source"],
  "limitations": ["Указать непроверенные допущения и границы вывода"]
}
```

Заполненную форму передают до истечения аренды:

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json submit ASSIGNMENT_ID result.json
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json assignments
```

Сдача ещё не начисляет кредиты. Принятый сервером текст фиксируется: тот же запрос можно повторить, но заменить результат нельзя. Источники и ограничения обязательны. Передача кода в JSON не запускает его на координаторе.

## 7. Проверьте вклад локально

Оператор открывает **«Проверка вкладов»**, читает результат и первичные источники, сопоставляет их с критериями. При необходимости отдельно воспроизводит расчёт в разрешённом окружении. В форме выбирает **«Принять вклад»** или **«Отклонить вклад»**, указывает обоснование и сохраняет решение.

Решение окончательное. Повторное сохранение того же решения не начисляет награду снова. У шлюза участников нет маршрута приёмки: исполнитель не может выдать себе кредиты через свой API. Результат автоматически не публикуется; преобразование в новую сводку требует отдельного решения и подтверждения прав.

Отмена предложения закрывает новые работы и отменяет несданные аренды; уже сданные результаты остаются доступны для проверки. Отзыв участника блокирует credential и будущий доступ, сохраняя журнал. Операции доступны локальному API `POST /api/federation/cancel` с `{offer_id,reason}` и `/api/federation/revoke` с `{member_id,reason}`; отдельных кнопок для них в текущей панели нет.

## 8. Обменяйте кредиты на доступ

Участник узнаёт баланс и `resource_id`, затем выполняет:

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json member
python -m workbench.federation.client --url http://127.0.0.1:8767 resources
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json redeem RESOURCE_ID
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json access RESOURCE_ID
```

`redeem` создаёт право чтения и списывает стоимость один раз. Повтор не списывает кредиты снова. `access` возвращает текст только после выдачи права; даже бесплатная сводка требует `redeem`. Пользуйтесь содержимым в пределах лицензии. Членство не открывает все материалы проекта, геномы или внешние учётные записи.

## 9. Подключение с другой машины

По умолчанию службы доступны только локально. Для внешнего подключения публикуется отдельный шлюз, административная консоль остаётся на loopback. Следующий вариант запускается **вместо** работающего `local-network`, иначе порты будут заняты.

В первом терминале координатора:

```sh
python -m workbench serve --port 8765
```

Во втором, после подготовки собственного DNS-имени, проверяемого сертификата и правил сети:

```sh
python -m workbench federation-gateway --host 0.0.0.0 --port 8767 --certfile /path/to/fullchain.pem --keyfile /path/to/private-key.pem --public-base-url https://research.example.org:8767
```

Замените демонстрационное имя и пути своими. Это отдельные консоль и шлюз федерации; доверенные workers для прежних миссий настраиваются отдельно по [NETWORK_DEPLOY_RU.md](NETWORK_DEPLOY_RU.md). Для собственного состояния у обоих процессов должен быть одинаковый `--data-dir`.

Внешний участник использует `--url https://research.example.org:8767`. Сертификат должен проверяться его системой. Для частного центра сертификации доступен `--ca-file /path/to/trusted-ca.pem`; проверки TLS не отключаются. `public_base_url` задаёт ожидаемый Host. Шлюз поддерживает внешнюю привязку IPv4, проверяет запросы и не предоставляет административные маршруты.

Не публикуйте порт консоли. Встроенный rate limit — 120 запросов за минуту на непосредственный peer, одновременно до 32 соединений. Это ограничения прототипа, не подтверждение промышленной устойчивости. Живой межмашинный TLS-сценарий не входит в сохранённую loopback-проверку поставки.

## 10. Проверка, ошибки и состояние

```sh
python scripts/verify_federation.py
python -m workbench doctor
```

Проверка использует временное состояние, отдельный локальный шлюз и 16 процессов CLI. Она проходит цикл на синтетическом агрегированном QC-примере, проверяет отказ без права, повторную сдачу, однократное начисление и списание. Внешние агенты не вызываются; это не исследование генома. Протокол: [examples/federation_exchange_run.json](../examples/federation_exchange_run.json). Проверка четырёх живых каталогов: [examples/federation_discovery_live.json](../examples/federation_discovery_live.json).

| Ситуация | Что проверить |
|---|---|
| Приглашение отклонено | Срок, одноразовость, открытое предложение, точный хеш условий; при необходимости выпустить новое |
| CLI не читает секретный файл | Владелец/права `0600` на POSIX, обычный файл без symlink, правильный путь; в Windows — ACL |
| Не получается присоединиться повторно | Клиент не перезаписывает credential-файл; для нового допуска нужен другой путь |
| `claim` не даёт аренду | Приглашённый offer, его срок и свободные места; прежний ключ возвращает прежнюю попытку |
| Сдача после срока | Просроченная аренда не принимает поздний результат; нужна новая допустимая попытка |
| `access` возвращает `403` | Credential для этого URL, отсутствие отзыва и предварительный `redeem` ресурса |
| Недостаточно кредитов | Работа должна быть принята; учитываются цена ресурса и предыдущие обмены |
| `429` | Дождаться конца минутного окна, уменьшить частоту; не опрашивать без ограничений |
| Карточка/каталог недоступны | Отдельный отчёт провайдера; отсутствие ответа не означает отсутствие проекта |

Экспорт доступен по `http://127.0.0.1:8765/api/federation/export`. Он содержит метаданные и журнал, но не секреты, тексты результатов и содержимое сводок. Для полной резервной копии остановите все процессы координатора и сохраните состояние в защищённом месте; экспорт не заменяет копию SQLite. Секретные файлы не включайте в распространяемый архив проекта.

## 11. НИОКР и интерпретация результата

Практический результат цикла — прослеживаемый вклад с источниками, критериями, локальной проверкой и контролируемым доступом. Для генома человека здесь допустимы публичные методические сравнения и разрешённые вычислительные задачи без передачи персональных геномов. Приёмка инфраструктурного задания не доказывает возможности изменять взрослый организм.

Отдельный `structural_plasticity` — синтетический эксперимент по структурной пластичности, инженерно интерпретирующий мотивы Савельева. Его интерфейс: **http://127.0.0.1:8765/morphogenesis.html**. Он не является валидированной моделью человеческого мозга или обещанием ускоренной эволюции. Параметры и допустимые выводы описаны в [MORPHOGENESIS_MODEL_RU.md](MORPHOGENESIS_MODEL_RU.md).
