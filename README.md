# Meta-Harness Research System 0.10.0

Исходники и задачи: [neuromorph-agent-os](https://github.com/Petr111111110000568/neuromorph-agent-os).

Версия 0.10 добавляет подключаемые среды исполнения **Unreal Agent** и **Pi**, веб-панель задач и MCP-интерфейс. Код адаптера, установленная программа, проверка протокола и авторизованный вызов модели имеют отдельные статусы. **OpenHands SDK**, Codex SDK и Claude Agent SDK изучены в [сравнительном отчёте](docs/HARNESS_COMPARISON_RU.md); доступ к их сервисам автоматически не предоставляется.

## Нулевой бюджет и сохраняемая история

Текущая конфигурация допускает только расходы **0**. `config/resource_policy.json` блокирует внешний inference OpenAI/Anthropic и live-вызовы harness даже при наличии API-ключей и `AUTONOMY_ALLOW_MODEL_CALLS=true`. Удаление policy-файла сохраняет запрет; неверная конфигурация приводит к ошибке. Бесплатные веб-чаты Qwen/DeepSeek используются отдельно и не являются API-подключениями этого кода.

Один цикл чтения публичных каталогов можно сохранить в ограниченный SQLite-журнал:
```sh
python -m workbench.autonomy --online --provider none --history-db runtime/discovery-history.sqlite
```
Каталог `runtime/` создаётся обычным выводом цикла. Повтор artifact не дублирует наблюдение, изменение revision/license меняет digest; время получения сохраняется отдельно. Журнал хранит до 2000 ресурсов, 10000 изменений и 2000 запусков. Это история в пределах хранения, а не вечный архив. Сбой SQLite откатывает журнал; три файла последнего отчёта записываются отдельно и не образуют с ним общую транзакцию.

Указанные ниже старые инструкции включения платных API не отменяют новую политику. Подробнее: [режим расходов 0](docs/ZERO_SPEND_RU.md).

## AI-исполнители

После запуска платформы откройте **http://127.0.0.1:8765/harnesses.html**. Панель показывает подключения, принимает текст задачи и сохраняет ответы с происхождением в локальной SQLite. Доступны также `GET /api/harnesses`, `GET /api/harnesses/runs`, `POST /api/harnesses/run` и MCP-инструменты `harness_status`, `harness_runs`, `run_harness_task`.

Вызовы модели требуют настроенного исполнителя, серверного API-ключа и `AUTONOMY_ALLOW_MODEL_CALLS=true`. В браузер ключ не передаётся. Адаптеры отключают командные и файловые инструменты и работают с отдельным пустым каталогом. Они возвращают текст предложения; научная проверка результата выполняется отдельно. Ограничения времени и размера вывода не задают денежный или токенный бюджет.

[Настройка адаптеров](docs/HARNESS_INTEGRATION_RU.md) · [Фактическая проверка версии 0.10](docs/HARNESS_DELIVERY_RU.md).

Автоматический GitHub-цикл версии 0.9 сохраняет отдельный прямой API-профиль с одним запросом на цикл; свободный цикл внешнего harness в расписание не включён.

[Фактический статус публикации и AI-подключений](docs/DEPLOYMENT_STATUS_RU.md): GitHub CI и первый discovery-цикл прошли; ежедневная задача ChatGPT включена, немедленный запуск запрошен. Завершённый вклад внешнего AI пока не подтверждён. Copilot вернул 403 при назначении; API OpenAI/Anthropic требуют ключей.

Версия 0.9 добавляет GitHub CI и ограниченный цикл развития: поиск публичных ресурсов, формирование задач, вызов настроенного API-провайдера и предложение изменений через pull request. Основной код изменяется после проверки владельцем. Поиск каталога не означает, что найденный агент принял участие.

## Автоматическое развитие в GitHub

Workflow `autonomy.yml` выполняется по расписанию и вручную из Actions. Результаты цикла сохраняются в artifacts. Без ключей работает обнаружение ресурсов и подготовка задач; LLM-вызов обозначается как недоступный. Для OpenAI или Anthropic нужны соответствующий Repository Secret и включение разрешения вызова в Repository Variables; точные имена и порядок описаны в [настройке GitHub](docs/GITHUB_AUTOMATION_RU.md).

Один цикл ограничен четырьмя каталогами, тремя записями на каталог и одним запросом к выбранному провайдеру. Полученный код сохраняется как предложение в разрешённых каталогах и не исполняется в процессе с правами публикации. Автоматического слияния нет.

Для внешних участников: [CONTRIBUTING.md](CONTRIBUTING.md), [AGENTS.md](AGENTS.md), [agent-project.json](agent-project.json). Действующие платформы и требования подключения разобраны в [обзоре интеграций](docs/AI_PLATFORM_INTEGRATION_RU.md). Наличие GitHub-проекта не заменяет подписку, API-ключ или согласие оператора внешнего агента.

Локальная проверка одного цикла без сетевых запросов:

```sh
python -m workbench.autonomy --config config/autonomy.json --output-dir runtime/autonomy --provider none
```

С добавлением `--online` выполняется ограниченное чтение публичных каталогов. Подробнее: [контракт автономного цикла](docs/AUTONOMY_ENGINE_RU.md).

Рабочий прототип исследовательской платформы: поиск научных ресурсов и кандидатов в участники, предложения вычислительных задач, добровольное присоединение внешних исполнителей, ручная приёмка результатов и обмен принятого вклада на доступ к разрешённым исследовательским сводкам.

В версии 0.8 добавлены обучаемая KAN, кортикальная модель контекстной памяти и совместная работа 11 программных ролей по аналогии с функциями областей мозга. Это воспроизводимые синтетические эксперименты и оркестрация по правилам; внешние LLM не настроены, модель человеческого мозга и биологическая эффективность не заявляются.

## Запуск

Нужен Python 3.11 или новее. Обязательных pip-зависимостей у ядра нет. Распакуйте проект и выполняйте команды из его каталога.

- Windows: запустите `start.cmd`.
- Linux/macOS: выполните `sh start.sh`.
- Альтернатива: `python -m workbench local-network`.
- Откройте **http://127.0.0.1:8765/brain.html** для новой рабочей области.
- Федерация участников: **http://127.0.0.1:8765/federation.html**.

Синтетический эксперимент по структурной пластичности доступен отдельно: **http://127.0.0.1:8765/morphogenesis.html**.

Запускаются локальная веб-консоль, координатор, SQLite, два процесса доверенных workers и отдельный шлюз внешних участников на `127.0.0.1:8767`. Шлюз workers использует порт `8766`. Закрытие браузера не завершает программу; Ctrl+C останавливает запущенные процессы. Состояние находится в `state/`. Исходная поставка не содержит личного состояния или действующих приглашений.

Для явного создания стартового предложения и авторской сводки проекта выполните в другом терминале:

```sh
python -m workbench seed-exchange
```

Команда создаёт примеры локально и не подключает внешних агентов. Повторный вызов не размножает стартовые записи.

## Возможности версии

1. Поиск в четырёх публичных каталогах: Agentverse, Hugging Face models, Hugging Face datasets и Official MCP Registry. По умолчанию используется локальный реестр; внешние API включаются явно.
2. Инспекция JSON-карточки по известному публичному HTTPS-адресу либо известному Tor v3 onion-адресу через отдельно настроенный локальный SOCKS5 proxy. Карточка хранится как данные; её команды и endpoints не запускаются.
3. Реестр кандидатов с происхождением и заявленными возможностями. Сопоставление кандидата с предложением и подготовка текста о пользе участия. Текст остаётся черновиком, без рассылки.
4. Собственный протокол `meta-harness-contribution/1`: одноразовое приглашение, явное принятие фиксированных условий, ограниченное членство, аренда задачи, представление результата с источниками и ограничениями.
5. Ручная приёмка через локальную консоль. Непередаваемые неденежные кредиты начисляются за принятый результат; повторный запрос не начисляет их снова. Кредиты расходуются на право чтения разрешённых сводок.
6. Сохранённые исследовательские миссии: публичные метаданные → триаж аннотаций Europe PMC → методический расчёт → журнал результатов и утверждений. Роли совета реализованы правилами; внешняя LLM не настроена автоматически.
7. Распределённая очередь доверенных workers с арендой, повторами, отменой и восстановлением. Инспекция исходного ZIP по закреплённому commit и лицензии без установки чужого кода.
8. Ограниченный MCP stdio-интерфейс: **32 инструмента**, согласование legacy-версии `2025-11-25`. Пять инструментов управляют сессиями Brain; три — подключаемыми средами AI. Полная A2A-совместимость не заявляется.
9. Синтетический вычислительный эксперимент `structural_plasticity` по структурной пластичности — инженерная интерпретация мотивов Савельева. Область модели и ограничения изложены в [описании эксперимента](docs/MORPHOGENESIS_MODEL_RU.md).
10. `kan_benchmark`: двухслойная KAN с обучаемыми функциями рёбер, базисами spline/RBF/wavelet и контрольными MLP/линейной регрессией. Это собственная ограниченная реализация; оригинальные pykan, FastKAN и Wav-KAN изучены, но не установлены.
11. `cortical_sequence`: контекстные клетки, локальное обучение дистальных связей, прогноз последовательностей и сравнение с Markov-0/1/2. Реализация вдохновлена моделью активных дендритов, но не воспроизводит HTM, CORNN или Monty полностью.
12. Brain: локальные источники → план → три задачи доверенным workers → проверка происхождения → сравнения по seed → общее рабочее пространство. Сессии, память и намерение отмены сохраняются в SQLite. Вопрос задаёт контекст и поиск источников; произвольное научное исследование из текста автоматически не синтезируется.

## Как работать с новой панелью

На `brain.html` задайте вопрос, выберите от одного до трёх модулей, seed и класс данных. Запустите сессию: координатор автоматически передаёт задачи двум workers, а панель показывает роли, события, результаты, источники и ограничения. Завершённые сессии доступны после перезапуска; следующая сессия может извлечь прошлый вычислительный эпизод. Результаты разных задач не объединяются в одну оценку «интеллекта».

Во вкладке лаборатории задавайте параметры KAN или кортикального модуля отдельно. После реального расчёта появляются графики функций рёбер либо активности клеток, контрольные сравнения и JSON-результат. Загрузка внешних данных, изображений, геномов и обучение моделей на них в эти два модуля не входят.

## Как пригласить исполнителя

В веб-консоли найдите кандидата, создайте предложение с критериями приёмки и подготовьте черновик. После согласования с оператором исполнителя выпустите приглашение:

```sh
python -m workbench invite --offer OFFER_ID --out private/invitation.json
```

Подставьте ID существующего предложения. Команда создаёт файл однократно с правами `0600` на POSIX; в Windows дополнительно проверьте ACL. Токен не печатается в консоли и не включается в экспорт. Передайте файл согласованным защищённым способом.

Участник на той же машине может присоединиться командой:

```sh
python -m workbench.federation.client --url http://127.0.0.1:8767 --credentials private/member.json join --name research-agent --capabilities literature_review,method_reproduction --invitation-file private/invitation.json --accept-terms
```

Для другой машины нужен доступный **HTTPS-шлюз** с проверяемым сертификатом. `127.0.0.1` всегда означает машину, на которой выполняется команда. Полный цикл `claim → submit → review → redeem → access` и настройка TLS описаны в [руководстве федерации](docs/FEDERATION_USER_GUIDE_RU.md).

## Что подтверждено

В [протоколе проверки обмена](examples/federation_exchange_run.json) сохранён успешный локальный HTTP-сценарий: 16 отдельных процессов клиентских команд, вступление, аренда, передача результата, ручная приёмка, однократное начисление, обмен и доступ. Это процессы проверки протокола, а не 16 привлечённых внешних агентов. Расчёт использовал синтетические агрегированные метаданные; геномы человека не использовались.

[Живая проверка каталогов](examples/federation_discovery_live.json) 24 сентября 2026 года получила по три карточки из каждого из четырёх каталогов. Каталоги были доступны на момент проверки; найденные исполнители не были вызваны или присоединены. Живое соединение с onion-сервисом и развёртывание на нескольких физических машинах в эти подтверждения не входят.

## Границы применения

Это прототип инфраструктуры НИОКР. Он поддерживает обзоры литературы, проверку качества разрешённых публичных данных и воспроизведение вычислительных методов. Персональные геномы, медицинские записи, закрытые исследовательские данные и чужие материалы без права передачи не входят в обмен. Метки класса данных и подтверждения прав задаёт оператор; они не являются автоматической экспертизой содержимого.

Поиск ограничен реализованными каталогами и явно заданными карточками. Сканирование всей сети, обход закрытого доступа, фактическая рассылка, самостоятельные регистрации и финансовые операции не выполняются. Найденная модель, набор данных или MCP-сервер не обязательно является самостоятельным агентом. Участник с токеном — допущенный исполнитель, принадлежность которого организации отдельно не удостоверена.

Внешняя система выполняет свою работу в собственном окружении и передаёт ограниченный JSON-результат. Прототип не исполняет полученный код и не предоставляет универсального адаптера к любой агентной платформе. Процесс Python не является песочницей для недоверенного кода.

Статус `completed` или принятый вклад не доказывает научную гипотезу. Платформа не предсказывает итоговый фенотип и не подтверждает возможность ускорения эволюции взрослого человека. Для научных выводов нужны отдельные проверяемые модели и независимое воспроизведение.
